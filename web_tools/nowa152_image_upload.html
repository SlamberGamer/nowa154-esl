Send protocol details

Needs Chrome / Edge. Send sequence: 05 01 hold → 00 FF clear both planes → 02 00 00 → 13×03 (black/white, 3040 B) → 06 01 switch to red plane → 13×03 (red, 3040 B, skipped if there are no red pixels) → 01 full refresh.

Time sync notes

Sent over the RxTx channel as DD + 4-byte big-endian unix seconds (built-in firmware command, no reflash needed). The clock face shows the sent value directly (modulo), so the time zone is already added in. Device time resets to zero on reboot and runs about 27 seconds slow per day; re-sync periodically or pre-compensate with a positive offset. After syncing, the clock face is usually redrawn immediately (within about 1 minute at most).

FLASH FIRMWARE // UART (click to open)

This is the original USB-COM Flash Writer by atc1441, loaded inside this page. It needs internet access and Chrome or Edge (Web Serial). Flash a .bin from this repo's bin/ folder, for example ATC_Paper_nowa154_me_card.bin.

  1. Wire the USB-UART adapter: TX → SWS on the tag, plus VCC and GND.
  2. Press Load flasher here, choose the baud rate and the firmware file, then open the COM port and flash.
  3. When it finishes, unplug the UART wires so the tag can run.
Open in a new tab

If the serial port list stays empty inside the frame, use "Open in a new tab" instead; some browsers block Web Serial in embedded pages.
